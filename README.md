# 🚀 Client-Side Blog CMS

A responsive client-side Blog Content Management System built using HTML5, CSS3, JavaScript, and LocalStorage.

This project allows users to create, edit, preview, publish, draft, search, filter, and delete blog posts directly from the browser without requiring a backend server.

---

## 📌 Project Overview

The Client-Side Blog CMS is a lightweight content management application designed to demonstrate CRUD operations and browser-based data persistence.

All posts are created by the user and stored locally using the browser's LocalStorage API.

No backend database or external API is required.

---

## 🎯 Objective

The objective of this project is to practice:

- Create, Read, Update and Delete operations
- JavaScript DOM manipulation
- LocalStorage
- Dynamic UI rendering
- Form handling
- Search and filtering
- Status-based content management
- Responsive web design

---

## ✨ Features

### 📝 Post Management

- Create new blog posts
- Edit existing posts
- Delete posts
- View complete posts
- Unique ID for every post
- Automatic creation timestamp
- Automatic update timestamp

### 📊 Post Status

Posts can have two statuses:

- Draft
- Published

Users can filter posts based on their status.

### 🔎 Search

Search posts using:

- Title
- Description
- Content

### 👁️ Post Preview

The application provides:

- Live editor preview
- Full post preview
- Post metadata
- Status information

### 💾 LocalStorage

All user-created posts are stored in browser LocalStorage.

The data remains available after refreshing the page in the same browser.

### 📱 Responsive UI

The interface is designed for:

- Mobile phones
- Tablets
- Desktop screens

### ⚠️ Delete Confirmation

Users must confirm before permanently deleting a post.
